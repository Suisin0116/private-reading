因子模型：暴露、收益与风险价格

用一套统一符号，厘清 β / X、F / f 与 λ 的角色，以及时间序列、横截面和 Fama–MacBeth 回归之间的关系。

1. 统一框架

多因子模型的基本思想是把资产收益拆成共同因子解释的部分与特质部分。若使用超额收益，常写为：

Rᵉi,t = αi + β′iFt + εi,t
βi / Xi,t
资产对因子的暴露，回答“带有多少因子属性”。
Ft / ft
第 t 期因子实现收益，回答“本期因子赚了多少”。
εi,t / ui,t
模型未解释的当期收益，即特质收益或残差。
修正：α 是时间序列回归中的平均定价误差或异常收益；ε 是每期残差。两者不能笼统地都叫“无法解释的部分”。

2. 因子暴露：β 与 X

暴露有两种主要来源，因此不必都写成 β。

时序回归暴露

用资产历史收益对已知因子收益回归，β 衡量共同波动敏感度。例如市场 β=1.2 表示市场超额收益变化 1%，该资产的条件超额收益平均变化约 1.2%，并不保证资产实际涨跌恰好为 1.2%。

特征型暴露

Barra 或量化选股常直接用公司特征构造 X，如 ln(市值)、账面市值比、动量、行业哑变量。连续特征通常先去极值、标准化和必要的中性化。

所有 β 都是暴露；但暴露也可以来自公司特征，此时更常记为 X。特征暴露和时序 β 的统计含义不同，不能只因名称相同就互换。

3. 因子实现收益：F 或 f

Ft 通常是可交易因子组合在第 t 期的收益。例如 SMB 是小盘组合减大盘组合，HML 是高账面市值比组合减低账面市值比组合。给定暴露后，因子对当期资产收益的解释为：

因子贡献 = β′iFt

例如 F=(2%, 1%, -0.5%)′，β=(1.2, 0.8, -0.3)′，则贡献为 3.35%。这是模型解释值，不等于该股票的完整实际收益，还需加上 α 与 ε。

修正：排序法得到的多空组合是“因子模拟组合”。若构造时没有充分控制其他暴露，它不一定是纯因子收益。

4. 因子风险价格：λ

横截面定价关系通常写为：

E(Rᵉi) = β′iλ

β 是风险数量，λ 是每单位暴露对应的预期收益补偿。逐期横截面回归中，λt 是该期的横截面斜率；其时间平均值 λ̄ 才是样本中的平均风险溢价估计。

关键区分：Ft 是因子模拟组合的实现收益；λt 是横截面回归估计的因子价格。若因子组合能准确复制定价因子且模型成立，两者可能接近，但一般不应写成同一个概念。

5. 两类回归回答不同问题

时间序列回归横截面回归
观察维度同一资产，跨多个时期同一时期，跨多只资产
因变量资产超额收益 Rᵉi,t多只资产的当期或未来收益
自变量已知因子收益 Ft预先得到的 β 或当期特征 X
主要输出因子暴露 β、时间序列 α因子价格/特征回报 λt
典型用途收益解释、业绩归因、模型检验估计特征回报、检验横截面定价

特征横截面模型常写为 rt=Xtft+ut。此处 ft 是给定特征定义下的当期因子回报，属于回归斜率；它与学术资产定价中的风险价格 λ 在形式上相似，但经济解释取决于暴露如何定义。

6. Fama–MacBeth 两步回归

历史收益与因子收益→第一步估计 β̂i→每期横截面回归→得到 λ̂t→时间平均并检验
第一步：Rᵉi,τ = ai + β′iFτ + εi,τ
第二步：Rᵉi,t = λ0,t + β̂′iλt + ui,t
平均价格：λ̄ = (1/T)Σtλ̂t

若暴露随时间变化，可用滚动窗口估计 β̂i,t，但必须保证只使用 t 时点可获得的数据。

修正与补充：经典 Fama–MacBeth 标准误需要处理 λ̂t 的时间序列相关；实践中常用 Newey–West/HAC。第一步 β 的估计误差还可能带来误差变量偏差，必要时采用组合排序、滚动估计或 Shanken 类修正。

7. Barra 型横截面风险模型

rt = Xtft + ut
Σr = XΣfX′ + Σu

X 包含行业和风格暴露，f 是当期因子回报，u 是特质收益。与传统时间序列模型相似之处在于都将收益拆成“暴露 × 因子回报 + 残差”；不同之处是 Barra 暴露多由横截面特征构造，并服务于风险预测与组合管理。

8. 一页速查

符号常见含义如何得到不要混淆
β收益对因子组合的敏感度时间序列回归不等同于公司特征本身
X横截面因子暴露公司特征、行业分类或模型估计尺度依赖于标准化方法
F / f因子实现收益多空组合或截面回归构造方式决定其经济含义
λ单位暴露的风险价格横截面回归单期 λt 不等于长期风险溢价
α平均异常收益/定价误差含截距回归不是每期随机残差
ε / u特质收益或残差实际值减拟合值均值、相关性取决于模型设定
口诀：β/X 看资产带多少因子，F/f 看因子本期实现多少收益，λ 看一单位因子暴露在横截面上值多少。

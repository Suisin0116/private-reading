多因子量化研究：从信号到组合

一套可落地的研究框架：先证明信号有效，再把信号映射为预期收益，使用风险模型和成本约束得到可交易组合，最后通过严格样本外回测验证。

1. 全流程与信息边界

1 候选因子2 数据与预处理3 有效性检验4 筛选与合成5 预测 Alpha6 风险与成本7 组合优化8 执行与评价

每一步都必须遵循时间可得性：在 t 日形成信号时，只能使用当时已经发布、可交易且可获得的数据；财务数据要使用实际公告日而非报告期末。

核心修正：原材料把研究、定价、风险和组合优化多次交叉重复。这里按“信号 → 预测 → 风险 → 权重 → 执行”的因果顺序重排，并将 Fama–French/Fama–MacBeth 放到各自的正确用途下。

2. 因子构建

基本面
估值（EP、BP、股息率、EV/EBITDA）、盈利（ROE、ROA、毛利率）、成长、质量、投资、杠杆、营运效率与预期差。财务比率需处理负分母、极端值和会计口径。
量价与微观结构
动量、反转、波动、流动性、成交量异常、订单流、价格冲击、日内/隔夜效应。频率越高，对交易规则、成本和数据清洗越敏感。
另类数据
分析师预期、公告事件、产业链、新闻/搜索情绪、ESG 与高频订单数据。重点不是“结果好不好”，而是结果相对事前预期的变化。
统计与机器学习
PCA、残差信号及机器学习特征。预测力可以强，但经济解释、非平稳性和数据挖掘偏差必须通过样本外检验约束。
风格与行业
市值、Beta、动量、残差波动、非线性市值、价值、盈利、成长、杠杆、流动性及行业哑变量。它们常被视作风险控制变量，也可能具有 Alpha 信息。
宏观与跨资产
利率、通胀、信用利差、汇率、商品和政策变量。对单只股票做同一时点横截面回归时，所有股票共享的宏观数值没有横截面变化，不能直接作为有效解释变量；应使用资产敏感度或交互项。
术语修正：“存货周期律”应为“存货周转率”；“市场 Beta”不是行业因子；ESG 既可能是替代数据来源，也可能成为风格暴露，分类取决于用途而非固定标签。

3. 数据预处理

  1. 样本定义：明确股票池、上市天数、ST/停牌、涨跌停、退市和可交易性规则。
  2. 缺失值：区分尚未披露、无意义和数据错误；不可随意用未来或全样本均值填充。
  3. 去极值：可用分位数截尾、MAD 或行业内稳健处理，参数只用训练期估计。
  4. 方向与标准化：统一“值越大预测收益越高”的方向，再做横截面 z-score 或 rank-gaussian。
  5. 风险中性化：将 Alpha 对行业、市值等控制变量做截面回归，残差作为净信号。
ft = Xtbt + et　⇒　f⊥t = (I − PX,t)ft

若使用 WLS，投影矩阵应与权重一致；OLS 下才有 P=X(X′X)⁻¹X′。类别变量需避免虚拟变量陷阱或采用明确约束。

中性化不保证提高 IC。最终组合严格控制什么风险，研究阶段就应在相同风险空间评价信号；若组合允许某类暴露，则不必机械清除。

4. 因子有效性检验

4.1 IC 与 Rank IC

ICt = Corr(fi,t, ri,t+1)
Rank ICt = Corr(rank(fi,t), rank(ri,t+1))
ICIR = mean(ICt) / sd(ICt)

Pearson IC 衡量线性关系，Spearman/Rank IC 衡量单调关系。双变量正态时，Spearman 相关与 Pearson 相关满足 ρS=(6/π)asin(ρP/2)；小相关附近约为 ρS≈(3/π)ρP，反推 ρP≈(π/3)ρS。

修正：月频 ICIR 若定义为均值除以月度标准差，年化通常乘 √12，而不是乘 12；显著性还要根据自相关采用 HAC/Newey–West 标准误。

4.2 Raw、Purified 与风险调整 IC

  • Raw IC：原始信号与未来收益的相关，可能包含行业、市值等共同暴露。
  • Purified IC：先对信号做风险中性化，再与未来收益相关。
  • Risk-adjusted IC：信号和实现收益在同一风险空间内残差化，并可按特质风险加权。

只有在投影方式、中心化、权重与风险空间都一致的特殊条件下，Purified IC 与 Risk-adjusted IC 才可能相同；“特质风险相同”本身并不足以保证二者相等。

4.3 分组、回归与稳健性

按信号从低到高分组 P1…P5。若高值代表更高未来收益，则做多 P5、做空 P1，检查单调性及 P5−P1 的净收益；若信号方向相反，则多空方向也应反转。

修正：原文同时写“从低到高”与“做多排名最高的第一组”，编号和方向矛盾。这里固定 P1 为最低、P5 为最高。

回归检验可采用逐期横截面或 Fama–MacBeth；稳健性包括替代定义、回看期、频率、股票池、市场状态、样本外/走步检验，以及扣除买卖价差、税费、冲击成本后的容量分析。

5. 因子筛选、去冗余与合成

5.1 增量信息而非简单相关性

候选因子先对已选因子做横截面正交化，其残差代表新增信息，再检验该残差对未来收益的预测能力。顺序正交化依赖加入顺序；若要顺序不变，可考虑对称正交化、正则化回归或直接联合建模。

θj,t = Fj,t − Proj(Fj,t | Fselected,t)
ri,t+1 = at + γ′tFselected,i,t + δj,tθj,i,t + εi,t+1

对 δj,t 的时间均值做 Fama–MacBeth/HAC 检验。大量候选因子时，还需控制多重检验和选择偏差；不能只挑样本内调整 R² 最大者。

5.2 合成方法

方法优点主要风险
等权简单稳健高度相关的一组信号被重复计权
IC 加权体现方向与平均预测力忽略稳定性与信号相关
ICIR 加权兼顾均值与波动分母噪声大，仍忽略因子间协方差
回归/正则化直接映射未来收益过拟合、系数漂移
均值-协方差权重考虑 IC 的联合稳定性协方差逆矩阵极不稳定，需收缩和约束
最大化预测 ICIR： w* ∝ Σ−1IC μIC

该式是无约束且矩阵可逆条件下的方向解；权重尺度需另行归一化，并建议加入收缩、换手、符号与权重上限约束。

6. 从因子得分到预测 Alpha

单因子最佳线性预测为：

Proj(r | f) = E(r) + Cov(r,f)/Var(f) · [f−E(f)]

若 f 标准化，横截面预测偏离可写作近似关系 α̂i ≈ IC × σr × zi。这是线性投影/校准公式，不应在没有线性条件期望假设时直接称为真实的 E(r|f)。实务中可用滚动横截面回归估计斜率 λ，再生成下一期预测，且必须防止前视。

多因子模型可以采用线性合成、Ridge/Lasso/Elastic Net、树模型或深度学习。复杂模型只有在严格时间序列交叉验证、成本约束和稳定性检查后才有意义。

7. 风险模型

风险模型不直接预测 Alpha，而是解释共同波动并估计资产协方差：

rt = Btft + εt
Σ = BΣfB′ + S

B 为风险因子暴露，Σf 为因子协方差，S 为特质协方差（常近似为对角阵，但并非理论上必须）。Barra 型基本面模型、PCA 统计模型和宏观因子模型的差别主要在 B 与 f 如何定义。

7.1 直接协方差与收缩

样本协方差在维度相对样本较高时噪声大，矩阵逆尤其不稳定。Ledoit–Wolf 型估计：

Σ̂shrink = δF + (1−δ)S,　0≤δ≤1

其中 F 是结构化目标，S 是样本协方差，δ 通过估计损失而选取。原笔记关于逆 Wishart 偏差的系数依赖协方差分母定义和自由度，不能脱离定义直接使用；实际建模优先采用经过验证的收缩估计器。

8. 组合构建、风险调整与成本

通用主动组合问题可写为：

maxw　α̂′w − (λ/2)w′Σw − Cost(w−wprev)
s.t.　1′w=0，l≤w≤u，行业/风格/换手/流动性约束

如果严格要求 B′w=0，系统风险项被消除，目标中的风险可简化为 w′Sw。加权投影后的 Alpha 为：

α̃ = [I − B(B′S−1B)−1B′S−1]α̂
w* = (1/λ)S−1α̃　（仅在等式约束、无边界及无成本的理想条件下）
公式修正：w′Σw 是组合方差，组合波动率是 √(w′Σw)。最小方差问题本身不使用预期收益；若要权衡收益与风险，应使用上面的效用最大化或设置目标收益约束。

真实组合还要处理个股上下限、成分股、行业偏离、整手、停牌、涨跌停、佣金、印花税、价差、滑点和非线性市场冲击。理论上的风险调整 IC 不一定能在这些不等式约束下直接转化为更高组合收益。

9. 执行、回测与评价

  • 执行：明确调仓频率、信号截止时间、订单生成、成交价假设、部分成交与再平衡。
  • 偏差控制：防止未来函数、存活者偏差、选择偏差；使用点时数据，正确处理复权、分红、退市和上市状态。
  • 样本划分：训练/验证/测试按时间前后划分；用滚动或扩展窗口做 walk-forward。
  • 绩效：年化收益与波动、Sharpe、最大回撤、信息比率、跟踪误差、换手、容量及因子/行业/个股归因。
最终判断标准不是单个因子的样本内 IC，而是冻结研究规则后，样本外、可交易、扣费且符合约束的组合表现。

10. 四类模型的边界

模型/方法主要问题核心输出
Fama–French 时间序列模型已知因子组合能否解释资产收益？资产暴露 β、时间序列 α
Fama–MacBeth 两步法因子暴露能否解释横截面预期收益？平均风险价格 λ̄ 及显著性
Alpha 预测模型哪些资产下一期相对更可能上涨？预测收益 α̂ 或排序分数
Barra 型风险模型资产为何共同波动，组合风险来自哪里？暴露 B、因子回报、Σf、S 与总协方差 Σ

Fama–French 是一种资产定价/收益解释模型；其中的规模、价值、盈利、投资等信息也可以作为 Alpha 候选，但“使用这些特征做预测”不等于“验证了 Fama–French 定价模型”。同理，因子合成权重决定信号如何组合，股票权重决定资本如何配置，两者必须分开。
